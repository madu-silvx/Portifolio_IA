# Como publicar no GitHub

Seu repositório atual é: `madu-silvx/Portifolio_IA`

Como a conexão do GitHub usada pelo ChatGPT está somente com acesso de leitura, os arquivos deste pacote não puderam ser enviados automaticamente.

## Opção 1 — pelo site do GitHub

1. Abra o repositório `Portifolio_IA`.
2. Faça backup do README atual, se quiser.
3. Use **Add file → Upload files**.
4. Extraia este ZIP no computador.
5. Arraste o conteúdo da pasta `Portifolio_IA_pronto` para o repositório.
6. Confirme o commit.

## Opção 2 — Git no computador

Depois de clonar o repositório, copie os arquivos deste pacote para a pasta clonada e rode:

```bash
git add .
git commit -m "Estrutura portfólio de IA"
git push origin main
```

## Importante

Os READMEs marcam projetos ainda não construídos como `Planejado` ou `Em desenvolvimento`.
Só altere para `Concluído` quando houver uma demo funcional e resultados medidos.

Nunca publique dados, prints, nomes de sistemas internos, documentos ou informações confidenciais da B3.
